# CampusConnect

Breaking study isolation through peer communities and skill-gap visibility.

CampusConnect is a college-focused peer-learning platform that helps students connect with peers, solve academic doubts, track their skill gaps, and connect with mentors.

## Features

### 📚 Study Communities

- Post subject-wise doubts
- Reply to other students' doubts
- Upvote useful answers
- Build a collaborative learning environment

### 🔒 Anonymous Doubt Mode

- Post doubts anonymously
- Ask questions without revealing your identity

### 🏆 Peer Leaderboard

- Earn contribution points
- Get points for posting doubts and replying
- Track community contributions through the leaderboard

### 📊 Skill-Gap Tracker

- Select your college branch
- Add the skills you already know
- Compare your skills with industry requirements
- Identify skills that you need to learn

### 👨‍🏫 Mentor Connect

- Faculty can create mentoring sessions
- Add meeting links and available seats
- Students can view available sessions
- Students can book mentoring sessions
